# 方案前沿台
纯静态、本地三指标帕累托筛选。允许用户自定义名称、单位、偏好和门槛，1–60方案。示例全为假设。

运行 `node build.cjs`，用静态HTTP服务器打开index.html。测试 `node --test tests/core.test.cjs`。

小为优cap上限/大为优cap下限（含等号），先约束筛选后做逐对严格支配。六位十进制输入放大为安全整数，比较无epsilon。相同数值不互相支配。缺失值/超过范围/重复名称报错，不导出过期结果。

localStorage保存有效条件；JSON导入先校验再替换。CSV防公式注入，HTML内容转义。CSV/MD完整；PNG只摘要和前沿前12项，随文字自适应增高。

没有后台、追踪、API密钥、推荐评分；未处理测量误差及未填写的产品特性。不是实际商品数据库。
